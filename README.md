# SEIRABMCuda

**GPU-accelerated agent-based SEIR epidemic simulator using NVIDIA CUDA**

## Overview

SEIRABMCuda is a high-performance epidemic simulation engine that models disease spread across 500,000+ agents using the SEIR (Susceptible-Exposed-Infectious-Recovered) compartmental model. Built on CUDA, it leverages GPU parallelism for real-time spatial contact detection, stochastic transmission, and intervention modeling.

## Key Features

- **Massive Scale**: Simulates 500,000+ agents in parallel on GPU
- **Spatial Contact Model**: Grid-based spatial hashing for efficient proximity detection
- **Stochastic Transmission**: Per-agent random number generation with configurable transmission probability
- **SEIR State Machine**: Gaussian-distributed incubation and infectious periods
- **Interventions**:
  - Lockdown with configurable mobility reduction
  - Vaccination with daily capacity and efficacy parameters
- **Configurable**: JSON-based configuration for all simulation parameters
- **Analysis Ready**: CSV output with Python plotting script included

## Requirements / Dependencies

### Hardware
- NVIDIA GPU with CUDA Compute Capability 3.5+
- Minimum 2GB GPU memory (4GB+ recommended for 500k agents)

### Software
- CUDA Toolkit 11.0+
- GCC 9.0+ (or compatible C++17 compiler)
- GNU Make
- Python 3.8+ (for visualization)
  - `pandas`
  - `matplotlib`

## Configuration

All simulation parameters are defined in `config.json`:

| Parameter | Description |
|-----------|-------------|
| `num_agents` | Total number of agents (default: 500,000) |
| `world_size` | Simulation area dimensions [width, height] |
| `duration` | Simulation length in days |
| `timestep` | Time increment per step (days) |
| `incubation_period` | E→I transition time (mean, std) |
| `infectious_period` | I→R transition time (mean, std) |
| `transmission_probability` | Infection probability per contact |
| `contact_radius` | Distance threshold for contact |
| `initial_infected` | Number of initially infected agents |
| `lockdown` | Optional: `{start_day, end_day, mobility_reduction}` |
| `vaccination` | Optional: `{start_day, daily_capacity, efficacy}` |

Example intervention configuration:

```json
{
  "lockdown": {
    "start_day": 30,
    "end_day": 60,
    "mobility_reduction": 0.7
  },
  "vaccination": {
    "start_day": 90,
    "daily_capacity": 5000,
    "efficacy": 0.9
  }
}
```

## Troubleshooting

### CUDA not found
```
error: cuda_runtime.h: No such file or directory
```
Ensure CUDA Toolkit is installed and `nvcc` is in your PATH:
```bash
export PATH=/usr/local/cuda/bin:$PATH
export LD_LIBRARY_PATH=/usr/local/cuda/lib64:$LD_LIBRARY_PATH
```

### Insufficient GPU memory
```
cudaErrorMemoryAllocation
```
Reduce `num_agents` in `config.json` or use a GPU with more memory.

### Compute capability mismatch
```
no kernel image is available for execution on the device
```
Update the `-arch` flag in `Makefile` to match your GPU:
```makefile
NVCCFLAGS = -O3 -rdc=true -arch=sm_75  # For RTX 20xx series
```

### Config file not found
```
Error: Could not open config.json
```
Run the executable from the project root directory where `config.json` is located.
